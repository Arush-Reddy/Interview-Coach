# Demo recording guide

Use this guide to record a concise **90-second product demo**. Record at
1080p, keep browser zoom at 100%, hide bookmarks and unrelated tabs, and use a
résumé created specifically for demonstration.

## Suggested sequence

### 0:00–0:10 — Problem and promise

Show the landing page.

Suggested narration:

> Interview preparation is usually generic. AI Interview Coach turns a
> candidate's résumé and a real job description into focused practice and
> measurable feedback.

### 0:10–0:25 — Add candidate context

- Select **Use a sample résumé** or upload a safe demo résumé.
- Show the target role and experience level.
- Expand the job-description field briefly.
- Select **Build my interview plan**.

### 0:25–0:40 — Show the personalized plan

- Point out résumé evidence, role match, and identified gaps.
- Generate the five interview questions.
- Mention that the parser rejects responses that do not contain exactly five
  questions.

### 0:40–1:05 — Practise an answer

- Open one question.
- Record a short answer or use a prepared typed answer.
- Request feedback.
- Show the score, strengths, improvements, suggested structure, filler count,
  and speaking rate.

### 1:05–1:20 — Progress and report

- Move between questions.
- Show the progress stepper and report page.
- If a completed sample session is available, download the Markdown report.

### 1:20–1:30 — Engineering close

Suggested narration:

> Gemini handles résumé-aware reasoning and qualitative feedback, while local
> Python validates generated structure and measures communication signals.
> Voice transcription runs through Whisper, and score history is opt-in and
> session-scoped.

## Evidence to keep with the submission

- Final demo video
- Landing-page screenshot
- Personalized résumé/role briefing screenshot
- Question-practice and feedback screenshot
- Completed report screenshot
- Public deployment URL
- GitHub repository URL
- Exact test result and date

Never record or publish a real API key, `.env` file, private résumé, personal
recording, or identifiable candidate data.
